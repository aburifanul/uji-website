Pertanyaan yang sering muncul

Belum ketemu jawabannya? Tanya langsung via WhatsApp.

Bisa deploy untuk project selain Laravel?

Saat ini baru Laravel. CodeIgniter, PHP Native, WordPress, dan Node.js sedang disiapkan. Kalau butuh yang lain, chat saja dulu.

Berapa lama pengerjaannya?

Deploy biasanya selesai dalam 1 hari kerja setelah semua data lengkap. Pembuatan website tergantung kompleksitas, umumnya 3 hari sampai 2 minggu.

Boleh pakai domain sendiri?

Boleh. Biaya konfigurasi mulai Rp50.000, sedangkan harga domain dibayar sendiri ke penyedia domain.

Pembayarannya bagaimana?

Deploy dibayar sebelum pengerjaan. Untuk pembuatan website, bisa DP dulu lalu pelunasan setelah website selesai. Detail dikonfirmasi lewat WhatsApp.

Source code-nya jadi milik saya?

Untuk jasa bikin website, ya. Source code dan akses diserahkan setelah pelunasan.
